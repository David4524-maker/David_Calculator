##  Cómo usar

### Opción 1 — Abrir el archivo HTML

1. Descarga `index.html` desde este repositorio
2. Haz doble clic → se abre en tu navegador
3. ¡Listo! La calculadora funciona offline

### Opción 2 — CodePen

1. Ve a [codepen.io/pen](https://codepen.io/pen)
2. Pega **todo el contenido** del `index.html` en la pestaña **HTML**
3. Verás la calculadora al instante

### Opción 3 — Servidor local

```bash
git clone https://github.com/David4524-maker/David_Calculator.git
cd david_calculator
python -m http.server 8000
# Abre http://localhost:8000 en tu navegador
